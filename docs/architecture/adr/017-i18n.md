# ADR-017: Internationalization (FR, DE, JP)

**Status:** Accepted  
**Date:** 2026-06-27  
**Sprint:** 4.5–4.6 (S-003)

## Context

Phase 4 requires UI and marketing localization for French, German, and Japanese markets.

## Decision

### SSOT package

- **`@xcreener/i18n`** — i18next + react-i18next
- Namespaces: `common`, `marketing`, `settings`
- Locales: `en` (default), `fr`, `de`, `ja`

### App wiring

- Desktop: `I18nProvider` in app providers; `locale` SQLite setting
- Web: provider in root; landing uses `marketing` namespace; optional `/fr` path via search param `?lang=`
- Mobile: Expo provider with device locale fallback

### CI

- `pnpm --filter @xcreener/i18n check:missing-keys` — fails if non-EN locale missing keys

## Consequences

- Tray labels deferred until app restart (documented in settings hint)
- Help/blog content remains English in v1; UI strings prioritized

## Alternatives considered

| Option | Rejected because |
|--------|------------------|
| react-intl | i18next better ecosystem for multi-app monorepo |
| Per-app duplicate strings | Violates SSOT in repo map |
