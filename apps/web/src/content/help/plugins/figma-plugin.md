# Figma plugin

The SnapGlow Figma plugin connects design frames with the public capture API.

## Setup

1. Team Pro API key from desktop Settings
2. Install the plugin in Figma (Development → Import plugin from manifest)
3. Enter your API key in the plugin UI

## Import

Select frames in Figma and import them as SnapGlow captures for beautify and export.

## Export

Push beautified captures back onto the Figma canvas for handoff docs and marketing assets.
