# Workspace setup

Team workspaces let admins invite members, apply a shared brand kit, and manage billing.

## Create a workspace

1. Open **Settings → Cloud sharing** and sign in
2. Scroll to **Team workspace**
3. Enter a name and click **Create workspace**

Or launch **Settings → Team setup guide** for a step-by-step wizard.

## Switch workspaces

Use the workspace switcher to move between personal space and team workspaces. Cloud uploads include the active workspace when applicable.

## Roles

- **Admin** — members, billing, brand kit, API keys
- **Editor** — create and edit team library items
- **Viewer** — read-only access
