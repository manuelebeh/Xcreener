# Real-time editing

Collaboration requires a **paid team workspace** (Team Starter or Team Pro).

## Start a session

From the editor, open **Collaboration → Start collaboration**. SnapGlow uploads the current capture and opens a WebSocket session.

## Web link

Copy the web link (`/c/:documentId`) so teammates can annotate in the browser. Remote cursors and annotation ops sync in near real time.

## Comments

Use the comments panel for threaded feedback. Mentions trigger in-app and optional email notifications.

## Requirements

Sign in to cloud sharing and select an active paid team workspace before starting collab.
