Embed polished screenshots on **Confluence Cloud** pages in one step.

## Requirements

- Xcreener desktop + cloud sign-in
- **Team Pro** workspace
- Confluence Cloud site linked to the same Atlassian OAuth app as Jira

## Connect Confluence

1. Open **Settings → Integrations**.
2. Click **Connect** next to Confluence.
3. Authorize with Atlassian — Confluence shares the same OAuth token as Jira when both are on the same site.

## Send an export

1. Finish editing your capture.
2. Choose **Send to → Confluence** in the export bar.
3. Select a page and optional message.
4. Xcreener uploads the image and appends it to the page body.

## Tips

- Use Confluence for release notes, QA reports, and internal docs.
- Pair with Jira when you need both a ticket attachment and a wiki page.
