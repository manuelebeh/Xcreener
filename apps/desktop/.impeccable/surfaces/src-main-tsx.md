# Surface brief: SnapGlow desktop (whole app)

Mode: Operate. Scope: main window (editor, library, settings) and capture overlay, phased. Phase 1: theme, shell, editor.
Audience and job: capturers and creators; quick pass or long polish. Constraint: stay close to category standards so users keep their habits.
Chosen direction: the category standard (standing exit, taken by the user in words), alongside CleanShot X, Pixelmator Pro, Shottr.
Unresolved: reference set delegated to the designer; capture overlay and cloud/team screens come in later phases.

## Direction contract

THESIS: The image is the subject; the app is native-feeling chrome that recedes. Refuses any experimental metaphor or non-standard navigation.
OWN-WORLD: Neutral cool-gray chrome (light and dark following the system), one blue accent for selection and primary actions, a darker neutral stage behind the canvas, system sans, 1px hairlines, 6px control radius, 10px panel radius.
STORY: A user captures, lands in the editor, tweaks format and style in a right inspector, and exports from the same place without hunting for controls.
FIRST VIEWPORT: Full-window layout with no page scroll. Top toolbar (wordmark left, segmented Editor/Library/Settings centered). Canvas stage fills the left, capture centered with a soft shadow. 320px inspector on the right with collapsible grouped sections, Export pinned at its foot. Primary action is Export, bottom of the inspector.
FORM: Docked-inspector editor, canon, candidate standing exit; seed key 66593253.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
